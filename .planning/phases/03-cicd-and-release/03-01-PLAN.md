**Title:** `# otelcol-tetragon`

**Subtitle/description:** "A custom OpenTelemetry Collector distribution with a native Tetragon gRPC receiver for streaming security events into the OTel pipeline without filesystem coupling."

**Badges (at top, after title):** CI workflow badge using `![CI](https://github.com/cilium/otelcol-tetragon/actions/workflows/ci.yml/badge.svg)` and GHCR link.

**## Overview**
Brief description: replaces the fragile filelog approach by connecting directly to Tetragon's gRPC `FineGuidanceSensors.GetEvents` streaming RPC. Streams all 10 event types (exec, exit, kprobe, tracepoint, loader, uprobe, lsm, usdt, throttle, rate_limit_info) as OTel LogRecords with full protojson body, extracted attributes, and proper severity mapping.

**## Usage**
```bash
docker pull ghcr.io/cilium/otelcol-tetragon:latest
docker run --rm -v ./config.yaml:/etc/otelcol/config.yaml ghcr.io/cilium/otelcol-tetragon:latest
```
Note: Container runs as non-root user `otel` (UID 10001). Health check endpoint on port 13133.

**## Configuration Reference**
Table of receiver configuration fields:

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `endpoint` | string | `localhost:54321` | Tetragon gRPC server address |
| `tls.insecure` | bool | `true` | Disable TLS verification |
| `tls.cert_file` | string | - | Path to client TLS certificate |
| `tls.key_file` | string | - | Path to client TLS key |
| `tls.ca_file` | string | - | Path to CA certificate |
| `retry.enabled` | bool | `true` | Enable exponential backoff on stream errors |
| `retry.initial_interval` | duration | `1s` | Initial retry backoff interval |
| `retry.max_interval` | duration | `30s` | Maximum retry backoff interval |
| `retry.max_elapsed_time` | duration | `0` (unlimited) | Maximum total retry time (0 = retry forever) |
