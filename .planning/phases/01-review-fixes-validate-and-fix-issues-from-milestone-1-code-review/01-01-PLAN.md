2. **Add `b.Reset()` after transient error, before `b.NextBackOff()` (RFX-02).** After the `ctx.Err()` check following `runStream` returns (line 116), and before `componentstatus.ReportStatus`, insert `b.Reset()`. The correct ordering in the `for` loop body after `runStream` returns should be:

```go
err := r.runStream(ctx, eventCh)
if ctx.Err() != nil {
    // Clean shutdown — do not reconnect.
    close(eventCh)
    consumeWg.Wait()
    return
}

// Stream had connected (or at least attempted); reset backoff so next
// retry starts from InitialInterval instead of accumulating.
b.Reset()

// Transient error — report and schedule retry.
componentstatus.ReportStatus(r.host,
    componentstatus.NewRecoverableErrorEvent(err))

wait := b.NextBackOff()

r.logger.Warn("stream error, reconnecting",
    zap.Error(err),
    zap.Duration("backoff", wait))

select {
case <-ctx.Done():
    close(eventCh)
    consumeWg.Wait()
    return
case <-time.After(wait):
}
```

Note: `b.Reset()` sets `currentInterval = InitialInterval`. Calling it before `b.NextBackOff()` means the first retry after a stream failure always uses `InitialInterval` (1s default). This is the correct behavior — if the stream ran successfully for hours and then failed, there is no reason to use accumulated backoff.

Also clean up the `backoff` import — after removing the `backoff.Stop` reference, verify the `backoff` import alias is still needed (it is, for `backoff.NewExponentialBackOff()`).

var lastBufferWarn time.Time

2. Replace the existing buffer warning block (lines 165-172) with a time-gated version:
```go
// Log a warning when the buffer nears capacity (80% threshold),
// rate-limited to avoid flooding under sustained backpressure.
bufLen := len(eventCh)
if bufLen >= int(float64(bufferSize)*bufferWarnPct) {
    if time.Since(lastBufferWarn) >= bufferWarnInterval {
        r.logger.Warn("event buffer nearing capacity",
            zap.Int("buffer_len", bufLen),
            zap.Int("buffer_cap", bufferSize),
            zap.Float64("utilization_pct", float64(bufLen)/float64(bufferSize)*100))
        lastBufferWarn = time.Now()
    }
}
```

The `lastBufferWarn` is a local variable in `runStream` — no struct field or sync primitives needed. The `bufferWarnInterval` const can be declared alongside the other consts at package level (`bufferSize` and `bufferWarnPct`) or locally. Local is preferred to avoid expanding the package API.
