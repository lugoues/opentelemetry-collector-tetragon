**Package-level var:**
```go
var jsonMarshaler = protojson.MarshalOptions{UseProtoNames: true}
```
This MUST be `UseProtoNames: true` — without it, protojson uses camelCase which breaks OpenObserve queries.

**Main function: `convertEvent(resp *tetragonv1.GetEventsResponse) plog.Logs`**

1. Create `plog.NewLogs()`, append ResourceLogs, ScopeLogs with `Scope().SetName("tetragonreceiver")`, append LogRecord.

2. **Timestamp (CONV-03):** Parse `resp.GetTime()` (a `*timestamppb.Timestamp`). Call `lr.SetTimestamp(pcommon.NewTimestampFromTime(resp.GetTime().AsTime()))`. Set `lr.SetObservedTimestamp(pcommon.NewTimestampFromTime(time.Now()))`.

3. **Body (CONV-02):** `body, err := jsonMarshaler.Marshal(resp)` — on error, set body to error string. `lr.Body().SetStr(string(body))`.

4. **Severity (CONV-04):** Type-switch on `resp.GetEvent()`:
   - `*tetragonv1.GetEventsResponse_ProcessExec`, `*tetragonv1.GetEventsResponse_ProcessExit`, `*tetragonv1.GetEventsResponse_ProcessLoader`: `SeverityNumberInfo` / `"INFO"`
   - `*tetragonv1.GetEventsResponse_ProcessKprobe`, `*tetragonv1.GetEventsResponse_ProcessTracepoint`, `*tetragonv1.GetEventsResponse_ProcessLsm`, `*tetragonv1.GetEventsResponse_ProcessUprobe`, `*tetragonv1.GetEventsResponse_ProcessUsdt`: `SeverityNumberWarn` / `"WARN"`
   - `*tetragonv1.GetEventsResponse_ProcessThrottle`, `*tetragonv1.GetEventsResponse_RateLimitInfo`: `SeverityNumberError` / `"ERROR"`

5. **Static attributes (CONV-05):** `attrs.PutStr("event.domain", "tetragon")` and `attrs.PutStr("event.name", eventTypeName(resp))`.

6. **eventTypeName helper:** Type-switch returning: `"process_exec"`, `"process_exit"`, `"process_kprobe"`, `"process_tracepoint"`, `"process_loader"`, `"process_uprobe"`, `"process_lsm"`, `"process_usdt"`, `"process_throttle"`, `"rate_limit_info"`, default `"unknown"`.

7. **extractProcess helper:** Type-switch to get the `Process` from each event type. `ProcessExec` has `GetProcessExec().GetProcess()`, `ProcessExit` has `GetProcessExit().GetProcess()`, etc. `ProcessThrottle` and `RateLimitInfo` return nil (no process field).

8. **Process attributes (CONV-06):** If process is non-nil:
   - `attrs.PutStr("tetragon.process.binary", proc.GetBinary())`
   - `attrs.PutStr("tetragon.process.arguments", proc.GetArguments())`
   - `attrs.PutInt("tetragon.process.pid", int64(proc.GetPid().GetValue()))` — safe: nil UInt32Value.GetValue() returns 0
   - `attrs.PutInt("tetragon.process.uid", int64(proc.GetUid().GetValue()))`
   - `attrs.PutStr("tetragon.process.exec_id", proc.GetExecId())`
   - `attrs.PutStr("tetragon.process.cwd", proc.GetCwd())`

9. **Parent attributes (CONV-07):** Extract parent via similar type-switch (`GetProcessExec().GetParent()`, etc.). If parent non-nil:
   - `attrs.PutStr("tetragon.parent.binary", parent.GetBinary())`
   - `attrs.PutInt("tetragon.parent.pid", int64(parent.GetPid().GetValue()))`
   - `attrs.PutStr("tetragon.parent.exec_id", parent.GetExecId())`

10. **Event-specific attributes (CONV-08):** Type-switch:
    - `ProcessKprobe`: `attrs.PutStr("tetragon.policy_name", e.GetPolicyName())`, `attrs.PutStr("tetragon.action", e.GetAction().String())`, `attrs.PutStr("tetragon.function_name", e.GetFunctionName())`

```go
func TestConvertEvent(t *testing.T) {
    tests := []struct{
        name     string
        fixture  string
        wantSev  plog.SeverityNumber
        wantName string
    }{
        {"process_exec", "testdata/events/process_exec.json", plog.SeverityNumberInfo, "process_exec"},
        {"process_exit", "testdata/events/process_exit.json", plog.SeverityNumberInfo, "process_exit"},
        // ... all 10
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            raw, err := os.ReadFile(tt.fixture)
            require.NoError(t, err)
            var resp tetragonv1.GetEventsResponse
            require.NoError(t, protojson.Unmarshal(raw, &resp))
            logs := convertEvent(&resp)
            require.Equal(t, 1, logs.LogRecordCount())
            lr := logs.ResourceLogs().At(0).ScopeLogs().At(0).LogRecords().At(0)
            // Verify scope name
            assert.Equal(t, "tetragonreceiver", logs.ResourceLogs().At(0).ScopeLogs().At(0).Scope().Name())
            // Verify severity
            assert.Equal(t, tt.wantSev, lr.SeverityNumber())
            // Verify event.name attribute
            val, ok := lr.Attributes().Get("event.name")
            require.True(t, ok)
            assert.Equal(t, tt.wantName, val.Str())
            // Verify event.domain
            val, ok = lr.Attributes().Get("event.domain")
            require.True(t, ok)
            assert.Equal(t, "tetragon", val.Str())
            // Verify body is non-empty JSON
            assert.NotEmpty(t, lr.Body().Str())
            // Verify timestamp is set (non-zero)
            assert.NotEqual(t, pcommon.Timestamp(0), lr.Timestamp())
        })
    }
}
```
