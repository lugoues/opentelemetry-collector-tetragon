## Tech Debt

### Phase 2: Distribution

1. **mise run smoke missing config mount** — The smoke task runs `docker run` without `-v` mounting the example config. The container cannot find `/etc/otelcol/config.yaml` and exits immediately. Fix: add `-v "$(pwd)/rootfs/etc/otelcol/config.yaml:/etc/otelcol/config.yaml:ro"` to the docker run command.

2. **ocb task output path undocumented** — `mise run ocb` uses `--output-path /tmp/otelcol-tetragon` while `builder-config.yaml` declares `output_path: /tmp/dist`. The divergence is intentional (per plan) but not documented for developers.

### Phase 3: CI/CD and Release

3. **README omits local build path** — The Build from Source section documents `docker buildx build` but not `mise run ocb` output location (`/tmp/otelcol-tetragon/otelcol-tetragon`).
